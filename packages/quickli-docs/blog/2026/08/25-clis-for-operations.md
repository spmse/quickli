Operations work values repeatability, composability, low overhead, and precise control.
Those properties are natural strengths of command-line tools, especially when a task must
run from a shell, a scheduled job, a container, or a recovery environment.

{/* truncate */}

CLIs also create durable interfaces between people, scripts, services, and infrastructure.
Their limitations are real, but a focused command with predictable text and exit behavior
can remain useful for years.
