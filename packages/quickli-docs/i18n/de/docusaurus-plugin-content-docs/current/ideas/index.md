# Projektideen

Diese Seite ist ein Ideen-Hub für Lernende, die mit `quickli` Python und CLI-Design üben
möchten.

## Ideen für dein nächstes Projekt

1. **Projekt-Scaffolding-Tool (`scaffy`)**
   - Erstelle eine Projektstruktur für häufige Anwendungstypen.
   - Initialisiere ein Git-Repository.
   - Bereite Starter-Dateien wie Ignore-Dateien, Issue-Templates, Pull-Request-Templates,
     Container-Dateien und README-Dateien vor.
2. **Compose-zu-Kubernetes-Manifest-Generator (`c2k`)**
   - Lies ausgewählte Docker-Compose-Services ein.
   - Erzeuge daraus eine begrenzte, explizite Menge an Kubernetes-Manifesten.
   - Halte die generierten Ressourcen nachvollziehbar und leicht überprüfbar.

:::tip[Teile deine Build-Story]
Wir suchen Builder. Wenn du mit `quickli` ein Tool gebaut hast, möchten wir gerne mehr über
deine App, deine Lernreise und dein Feedback zum Framework erfahren.

Bitte schlage eigene Ideen vor oder teile dein Projekt, indem du ein
[Issue](https://github.com/spmse/quickli/issues/new/choose) erstellst.
:::

In einer nächsten Iteration kann eine eigene Showcase-Seite für Community-Ideen und
abgeschlossene Projekte ergänzt werden.
