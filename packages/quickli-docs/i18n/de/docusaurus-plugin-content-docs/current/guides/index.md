# Implementierungsleitfäden

Diese Leitfäden erklären die Referenzbeispiele aus dem `quickli`-Quellpaket. Die Reihenfolge
führt von einem einfachen Einstieg bis zu einer Anwendung mit mehreren Befehlen.

## Voraussetzungen

Installiere quickli, bevor du ein Beispiel ausführst:

```bash
pip install quickli
```

Alle Beispiele laufen mit Python 3.12, 3.13 und 3.14.
